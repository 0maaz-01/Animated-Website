# Xentry Website Landing Page Clone 🚀

Welcome to the repository for the **Xentry Website Landing Page Clone**! This project is a clone of the Xentry landing page, designed to replicate its design and functionality. It's built for educational purposes, helping you learn about front-end development and web design by creating a clone of a real-world website. 🎓💻

---

## Features ✨

- **Responsive Layout**: Fully responsive, ensuring a seamless experience on mobile, tablet, and desktop devices 📱💻
- **Clean UI**: Mimics the modern and professional design of the original Xentry landing page 🖥️
- **Interactive Elements**: Includes buttons, forms, and smooth animations to enhance user experience 🖱️🔄
- **SEO Friendly**: Optimized with proper meta tags and heading structure for better search engine visibility 🔍

---

## 🚀 Tech Stack

 ![My Skills](https://skillicons.dev/icons?i=html) ![My Skills](https://skillicons.dev/icons?i=css)  ![My Skills](https://skillicons.dev/icons?i=js) ![Tailwind CSS](https://skillicons.dev/icons?i=tailwind) <img src="https://github.com/0maaz-01/Alaikoo_PDF_Reader_and_Editor./blob/main/Images/React.png" width="50" height="50"> 


- **HTML** : Structure and content of the website.
- **CSS** :  Styling and layout of the page.
- **JavaScript** :  Functionality and interactions.
- **Tailwind CSS** :  Utility-first CSS framework for fast and responsive design.
- **GSAP** :  High-performance animation library for smooth interactions.
- **React JS** :  Library for building the UI in a component-based architecture.
- **GSAP** : For adding animation in the website.
- **clsx** : For adding className to the elements dynamically in Tailwind CSS.
- **React Icons Library** : For adding icons to the buttons in the website.

## Installation 🛠️ :
You need to install some dependencies using the command terminal so that the code runs smoothly on your device.

1) React :
`npm install `

2) Tailwind CSS :
   `npm install -D tailwindcss@3 postcss autoprefixer`
     
    `npx tailwindcss init  -p`

4) clsx :
   `npm install clsx`

5) GSAP :
   `npm install @gsap/react gsap`

6) React Icons Library :
   `npm install react-icons --save`
