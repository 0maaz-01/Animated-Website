# Xentry Website Landing Page Clone

Welcome to the repository for the **Xentry Website Landing Page Clone**. This repository contains the source code for a clone of the Xentry landing page, designed to replicate its design and functionality. This project is meant for educational and practice purposes, allowing you to learn about front-end development and web design by building a clone of a real-world website.

## Features

- **Responsive Layout**: The landing page is fully responsive, adapting to various screen sizes and devices.
- **Clean UI**: The user interface mimics the design of the original Xentry landing page with a modern and professional feel.
- **Interactive Elements**: Includes interactive components like buttons, forms, and smooth animations.
- **SEO Friendly**: Optimized for SEO with proper meta tags, heading structure, and content organization.

## Tech Stack

- **HTML5**: For structuring the content.
- **CSS3**: For styling and layout.
- **JavaScript**: For adding interactivity and animations.
- **Bootstrap 5**: Used for responsive grid and layout.
- **Sass**: For more efficient and modular CSS management.
- **Parcel/Webpack**: For bundling the project files (optional).

## Installation

To run this project locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/xentry-landing-page-clone.git
   ```

2. Navigate into the project directory:

   ```bash
   cd xentry-landing-page-clone
   ```

3. Open the `index.html` file in your browser to view the landing page.

   Alternatively, you can use a live server for development:

   - Install a local server like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in Visual Studio Code and open `index.html`.
   - Or run a local server using npm (if you're using a bundler or other setup).
